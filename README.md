# 产品顾问团 · Product Advisory Council

把一个产品问题，交给五种思考视角讨论，形成可执行、可验证的决策建议。

**一个技能文件夹，五位顾问模块，75 张决策方法卡。** 可以单独请某个视角分析，也可以组织专家团，在带头像的群聊网页里讨论，并导出适合分享的长图或分图。

这里的顾问是 AI 运用整理后方法形成的分析视角，不是本人，不代表本人认可，也不保证真人顾问等效或商业结果。

## 可以帮你讨论什么

- 一个产品方向值不值得做，应该先服务谁。
- 功能优先级、定价、增长与商业模式的取舍。
- 发现同类产品后，怎样判断是否仍有机会。
- 资源有限时，如何缩小实验、检验假设和设置停止条件。

讨论从同一份业务简报出发，区分事实、假设与未知。最后给出建议、替代方案、关键分歧、最强反例及下一步实验，不按名人票数决定，也不强求所有视角达成一致。

## 安装一次即可

1. 在 [Releases](https://github.com/CarGod/product-advisory-council/releases) 下载 `product-advisors-public-v2.1.0.zip`。
2. 解压后保留完整的 `product-advisory-council/` 文件夹；不要只复制 `SKILL.md`，也不需要分别安装五个人。
3. 将该文件夹放入你的 AI 客户端支持的技能目录，或通过客户端技能安装入口导入完整技能包。客户端的具体支持与安装入口以其自身说明为准。

**Codex 本机安装：** 将整个文件夹放到 `~/.codex/skills/product-advisory-council/`；如果自定义了 `CODEX_HOME`，则使用该目录下的 `skills/`。安装后新开会话检查技能是否被发现。更新前先备份旧目录，再完整替换，避免旧文件残留。

如果曾安装五个 `product-advisor-*` 独立技能，先备份，确认新版能使用后移除旧副本，以免重复加载。

此包包含技能指令和本地辅助脚本，不附带模型或 API 密钥。纯文本评审需要能读取技能的 AI 客户端；检索与聊天脚本使用 **Python 3.9+ 标准库**，不需要安装第三方 Python 包。聊天网页和图片导出需要支持 JavaScript、Canvas 与下载功能的现代浏览器；宿主代理还需具备运行脚本、读写文件及打开本地页面的能力。未具备这些能力时，可使用纯文本评审。

## 直接这样问

**单人分析**

> 请用产品顾问团里的俞军视角分析：我们的免费工具准备增加订阅收费，应该怎么验证用户是否愿意付费？

**标准评审**

> 请产品顾问团用中档讨论：我想做一个 AI 笔记工具，但已有很多竞品。先帮我找最关键的差异化假设，再设计一个两周内能做的实验。

**充分讨论，生成聊天网页**

> 请产品顾问团用高档充分讨论：小团队应该先做增长还是先改善留存？请以群聊形式讨论，保留分歧，最后给出条件化决策和验证计划，并生成聊天网页。

**追加回应或收尾**

> @张小龙，请回应刚才俞军提出的反例。
>
> 收尾吧，列出我们已经确认的事实、仍未验证的假设，以及下一步该做什么。

**导出分享图**

> 把这次讨论导出为图片，保留聊天样式，按 9:16 智能分图。

提供目标用户、现有替代方案、实际数据、资源与期限，能让讨论更具体。未知的信息可以直接说未知，不必为了填模板编数据。

## 五档讨论深度

| 档位 | 讨论重点 | 计划交叉轮次／上限 |
| --- | --- | --- |
| 极速 | 建议、关键理由、最大未知、下一步 | 0／必要时 1 |
| 低 · 简短 | 替代方案、实质异议与验证动作 | 1／2 |
| 中 · 标准 | 假设对照、最强反例、判断修正与最小实验 | 2／3 |
| 高 · 充分 | 关键事实复核、竞争解释、压力测试与机会成本 | 3／5 |
| 极高 · 深度 | 情景敏感性、失败路径、证据缺口与最终反方复审 | 4／7 |

轮数是预算，不要求凑满；收敛后可以提前结束，信息不足时应明确交付条件和未完成项。选档后会在预算内自动推进，你可以随时插话、改档或要求收尾。未指定深度时会先询问；明确要求直接完成时默认采用中档并说明。

**档位不切换模型，也不设置模型内部思考参数。** 同一模型顺序生成多个视角，不等于多个独立模型讨论；使用方式应在报告中如实说明。详细规则见[讨论深度协议](product-advisory-council/references/discussion-depth.md)。

## 群聊网页与图片导出

网页包含头像、发言气泡、方法卡及决议卡。右上角的「导出长图」支持：

- 单张长图，保留聊天布局。
- 智能分图，可选 **9:16、9:19.5、3:4、4:5、1:1**。
- 按消息空隙分页；过长发言按段落或文字行拆分，尽量保留可读性。
- 预览后逐张下载，或打包下载。

聊天界面不调用模型，由宿主 AI 代理写入发言；本地服务仅监听本机，页面不加载外部资源。图片生成在浏览器本地完成，不会自动发布到社交平台。宿主 AI 客户端如何处理对话数据，仍取决于其自身服务和配置。

分享前请检查聊天正文中的业务与个人信息。图片导出不会自动删除这些内容。特别长的讨论建议使用分图；已有旧网页需从聊天记录重新渲染才能获得新功能。

## 决策卡与资料边界

公开包只保留方法摘要、适用条件、边界、提问和行动建议。卡片编号用于定位方法，**不是原文引用或事实证明**。

原始书籍、音视频、转写、网页、阅读笔记及卡片来源映射不随技能分发。技能不会自动查找你的私人资料目录。需要验证来源时，应另行提供资料或明确授权读取对应私有资料库，再说明实际核查范围。

此项目提供的是资料提炼后的决策方法工具，不是模型权重训练结果，也不能用方法卡替代对当下业务事实的核查。

## 目录结构

```text
product-advisory-council/
├── SKILL.md                 # 统一入口与单人／团队路由
├── advisors/                # 五个人物分析模块
├── references/              # 方法卡、讨论协议、简报与报告模板
├── scripts/                 # 统一检索与本地群聊运行时
├── assets/                  # 示意头像、网页与图片导出
├── agents/                  # 客户端展示元数据
└── manifest.json            # 发行文件清单与校验信息
```

辅助脚本示例（在技能文件夹中执行）：

```bash
python3 scripts/search.py '用户价值 定价' --person yu-jun --limit 6
python3 scripts/chatroom.py --help
```
