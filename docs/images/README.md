# Public presentation images

`council-overview.png` / `council-overview-en.png` present the current skill's 18 AI analytical perspectives and 255 method cards. These are illustrative portraits, not participation or endorsement by the people shown.

`decision-flow.png` / `decision-flow-en.png` illustrate the workflow: define a brief, compare and challenge options, then choose a conditional next step and a test. They are diagrams, not screenshots of a real discussion.

The matching SVG files are editable sources. Portraits are embedded in the overview SVGs; no remote images or local filesystem paths are required. PNG exports are used in the repository documentation for reliable rendering.

- Overview: 1440 × 940 px.
- Workflow: 1440 × 570 px.
- English versions use the `-en` suffix.

The existing `council-wall`, `method-front`, and `method-back` images (including `-en`) are retained screenshots from the separate interactive website. They are not a claim that the website has already been updated to match this skill release.
