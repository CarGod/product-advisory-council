# 功能与效果边界

工程测试验证方法检索、卡片归属、旧快照隔离、聊天渲染与导出功能，不证明建议准确率、商业效果或真人等效。

公开包只含原创方法摘要，不含原始来源或阅读笔记。方法 ID 不构成事实证据，来源资料不随包提供。外部事实与用户业务数据需另行核查。

测试应覆盖五档讨论深度、单张长图、智能分割、常见比例、ZIP、多页 PDF、方法编号与标题及右侧详情，以及历史卡片快照不能通过 HTML、API、Markdown 重新公开。用户正文由用户提供，不自动删改，转发前应审阅。

PDF 使用本机浏览器生成的 JPEG 页面封装为标准 PDF，不调用打印对话框，不依赖在线服务或外部字体。自动化检查覆盖 1／3／80 页的二进制偏移、流长度、页数限制和输入校验；这些检查不替代浏览器下载、中文头像显示及首尾页完整性的实际验收。PDF 是图像版，文字复制、全文检索及交互链接不在本次能力范围内。
